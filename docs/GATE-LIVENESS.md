# docs/GATE-LIVENESS.md

**The measurement P0 produces, and what it deliberately does not count.**

Writing a gate is free. The quantity that carries information is how many gates have been **observed
failing on a deliberately broken build**. A gate that has never gone red is a preference with a filename.

`docs/measurements/p0-gate-liveness.json` is regenerated by `make gates`. Its `gates_with_an_observed_red`
counts only gates whose named `broken_build` is currently injected by a passing test. **A gate with no
entry in `tools/gate_liveness.py::OBSERVED_BY` is not counted**, and that absence is the measurement rather
than a rounding-up opportunity.
