# docs/CORPUS-PROVENANCE.md — where every pinned corpus member came from

`docs/LICENCES.md` covers **resolved runtime dependencies** and is generated by
`ci/licence-denylist.sh`. This file covers **corpus members** — the artifacts the system reads and
quotes — and the **build-time tools** that turn them into pinned text. They are different questions
with different failure modes, and merging them would put a regulator's PDF in a table about wheels.

**Reproduction terms: NOT ESTABLISHED, and that is a state rather than a blank.**

`https://www.ifsca.gov.in/Pages/Contents/Disclaimer` was fetched on 16 August 2026 and read for a
copyright, reuse or reproduction statement. **It contains none.** What it does contain is an "as
is" warranty disclaimer, a statement that IFSCA accepts no responsibility for the accuracy or
completeness of material on the site, and conditions on linking to and framing the site. None of
those is a grant, and none is a prohibition.

No licence is asserted here, because none was found. Writing "Government of India material is
freely reproducible with attribution" would be a plausible sentence about a policy this project
did not read on this publisher's site, and a licence recorded from a general impression is the
same defect as a count recorded from an expectation. **What is recorded is what was checked, the
date it was checked, and the fact that it yielded nothing.**

What this build does rely on, and states plainly: the artifact is a **gazette notification of
subordinate legislation, published by authority**, retrieved from the issuing authority's own
website at a URL it publishes for that purpose. It is pinned here to be *read and quoted*, and the
system quotes it with its citation attached. Before any wider distribution of the PDF itself — as
opposed to quotations from it — the terms should be obtained from IFSCA directly. That is an open
item, not a settled one.

**Known to be stale on the day it was pinned.** This is the base notification of 19 February 2025.
Two amendment notifications are known and **not pinned**:

| notification | effect | status here |
|---|---|---|
| `IFSCA/GN/2025/007` | amends Chapter VI (other fund management activities), in force **30 July 2025** | NOT PINNED |
| `IFSCA/GN/2026/006` | IFSCA (Fund Management) (Amendment) Regulations, 2026 | NOT PINNED |

A consolidated text "amended up to July 30, 2025" is published by IFSCA and was **not** chosen: a
consolidation is an editorial artifact whose clause spans correspond to no gazette, and every G0
figure in this system is a character span into a specific published instrument. The amendments are
separate instruments and belong in the amendment graph, which is what an amendment graph is for.

## Build-time tools — not runtime dependencies, and not in `docs/LICENCES.md`

These produce `corpus/instruments/*.text.json`. Nothing in `src/` imports them; the pinned JSON is
what the system reads. They are listed here because **a build-time tool is still a tool whose
licence this project has an opinion about**, and `ci/licence-denylist.sh` scoped only to the
runtime set until this build.

| tool | version | licence | role |
|---|---|---|---|
| `pdfplumber` (over `pdfminer.six`) | 0.11.10 | MIT | **PARTY** — pure-Python content-stream reader |
| `pypdfium2` (over PDFium) | 5.13.0 | BSD-3-Clause / Apache-2.0 | **PARTY** — Google's C++ engine, the one in Chrome |
| `pymupdf` (over MuPDF) | 1.28.2 | **AGPL-3.0** or Artifex commercial | MEASURED, **NOT A PARTY** |
| `pypdf` | 6.16.1 | BSD | MEASURED, **NOT A PARTY** |

**`pymupdf` is excluded on its licence, and it is the arm that scored best.** `AGPL-3.0` is on this
repository's own `DENY` list in `ci/licence-denylist.sh`. That gate resolves the **runtime** set,
so a build-time tool passed straight by it — **a denylisted licence entering through a door the
gate does not watch.** The gate is extended to a build set rather than the exception being taken,
because an exception in a licence gate is how the gate dies, which is the same argument that fixed
the package name in `plan/00-decomposition.md` §1.

Reading an AGPL tool once to produce a published measurement distributes nothing. Depending on it
to build a shipped artifact would, and §13 would bite the moment the product served anything over
a network. The measurement stays; the dependency does not.

`pypdf` is permissively licensed and excluded for a different, measured reason: the instrument's
fonts carry **zero `/ToUnicode` CMaps**, so its width-heuristic word-boundary reconstruction has no
text-level check and it emits spurious **intra-word** spaces that whitespace collapsing cannot
repair.

All four arms' numbers are in `docs/measurements/S1-instrument-agreement.md`, including the two
that do not ship. A configuration is not made true by being measured first, and not made false by
being excluded.
