Read this first. It is short on purpose; the long documents are linked, not repeated.

## 1. Where the truth lives

| question | the ONE place |
|---|---|
| what are we building, and what is next? | **`docs/PLAN.md`** — the plan of record |
| what is the architecture, ACTUALLY? | **`docs/ARCHITECTURE-measured.md`** — from the import graph, regenerate with `make graph` |
| what is observed TRUE of the tree right now? | **`PROGRESS.md`** — regenerated by `make progress`, never hand-edited |
| what changed, and what was found wrong? | **`docs/AUDIT-TRAIL.md`** — append-only, checked both ways |
| what is still open? | **`docs/OPEN-ITEMS.md`** — rendered INTO the product |
| why was a choice made? | **`docs/decisions/D-*.md`** |
| what did a measurement actually produce? | **`docs/measurements/*.md`** |

`docs/ARCHITECTURE-rules-and-evidence.md` and `docs/EXPERIMENT-PROGRAMME.md` are **dated records**.
Never edit them to match a later result — the second is a pre-registration, and rewriting a
criterion after seeing its result is the exact failure it exists to prevent. Amendments go in
`PLAN.md §11`.

## 2. Before you believe any result

```bash
pgrep -f pytest        # the negative-control suite INJECTS into src/ while it runs
```

**Never read `git status` or `git checkout` a file while a suite is running.** Injectors plant
defects into real files and restore them after; mid-run they look like stray edits. Doing this
corrupted a full run in this repository. A genuinely orphaned injection is real — a killed run
leaves the file dirty — so the check is worth doing, **only when nothing is running**.

Any agent that RUNS this repo's tests needs `isolation: "worktree"`. To READ the tree while a
sweep is running, `git worktree add` a detached HEAD — injectors touch the working tree, not
`.git`, so a worktree is a safe view.

## 3. The rules that are not style

- **Check the exit code, not the tail.** `make verify | tail` returns *tail's* status. Use
  `set -o pipefail` or capture to a file. This is still catching people — a suite reported "exit
  0" through a pipe on 20 Aug 2026 while six tests were failing.
- **A partial view is not a reading.** `tail -4 | head -3` of `ci/GATES.md` showed rows up to 130
  and the next id was taken as 131. Row 131 already existed; the registry parser raised and four
  contract tests went red.
- **A gate that has never been observed RED is not evidence.** Every new gate needs a row in
  `ci/GATES.md` **naming its TEST, not its catalogue id** (`gate_liveness.py` resolves the name and
  derives the observation from the sweep; a catalogue id makes it hand-run only), a dated argument
  in `docs/GATE-CHANGES.md`, an entry in `tests/negative/catalogue.yaml` with a guard that
  **actually flips**, and the pre-registered LIVE set updated.
- **Each half of a check needs its OWN injector.** An allowlist has two failure modes — an
  undeclared entry, and a table full of entries nobody reaches. One injector flips one of them and
  leaves the other permanently green. Cross them.
- **Prefer the POSITIVE form.** A denylist refuses only what somebody remembered to write down;
  this project has been bitten by that five times. An allowlist refuses everything undeclared.
- **A count is not a reading.** Open the bucket. 351 of 498 "labels" were the word `NA`; 810
  "UNPARSEABLE" rules were parseable; a graph of 9,361 nodes had **zero edges**; 129 "disputed"
  PDF units were 102 one parser's normaliser, 21 misalignment, and 8 real. Every one had a
  plausible total.
- **Assert your anchors.** An edit whose anchor moved silently does nothing. Injectors here assert
  theirs and one caught a wrong anchor the same day it was written.
- **A negated character class matches NEWLINES.** `[^=]*` in a gate's regex ran past the line it
  meant and read a later tuple.
- **`absent != empty != zero`.** Every refusal takes a reason from a CLOSED vocabulary.
- **No fraction without both integers.** `ci/no-bare-rate.sh`.
- **Grep before citing.** Before writing *"`<file>` records X"*, grep it. A measurement here once
  attributed a number *and a quotation* to a file containing neither — the source was its own
  author's docstring.

## 4. The architecture, in one screen

`src/cdfc/evidence/run.py` is **THE DRIVER** — one function, one place where layer order is decided.

```
LAYER 1  DETERMINISTIC  corpus -> Provision (eId + exact span) · template -> Field (declared type)
LAYER 2  THE MODEL      proposes rule->field bindings AS DATA. It decides nothing.
LAYER 3  DETERMINISTIC  G-QUOTE · G-FIELD · G-TYPE · G-VOCAB · G-XREF
                        ONLY ADMITTED PROPOSALS BECOME NODES
LAYER 4  DETERMINISTIC  graph + coverage, over a denominator that is not arguable
LAYER 5  MIXED          precedence in PYTHON before any engine; then chaining
```

**THE SEAM.** `run()` takes `proposals: Path` — a FILE. The model writes proposals as data and the
driver reads them, so the model is never called from the verdict path because it is not called at
all. `model.propose()`/`.extract()` take a `transport` so any provider can be substituted without
touching the promise: **a failed call never looks like a clean empty result.**

**FOUR POPULATIONS, never merged.** corpus/statute · template · source document · entity. A
statute's `FME` is a concept; a custodian row's `FME` is an identity. `Record`/`Entity` are the
user's files; model-extracted entities are `ResolvedBy.MODEL` and are never counted as evidenced.

**Zero model calls is a property of the import graph**, not a promise: `cdfc.pathm` and
`cdfc.evidence` are `VERDICT_ROOTS` in `tests/negative/importgraph.py`.

**The runtime closure is MEASURED, not described** — `celpy`, `lark`, `lxml`, `openpyxl`, `yaml`,
`z3`. That list is `RUNTIME_THIRD_PARTY` and anything absent from it is refused by default. It says
six because the closure holds six; this file said three until B3 walked the graph. Docling,
LangExtract, networkx, rdflib and **splink** are build- or measurement-time. `cdfc.ingest` is
INSIDE the closure, so a PDF reader may not live there — build-time readers go in `tools/`.

## 5. The claim, and what it is not

> Upload your exports in whatever shape they arrive. We read them, link the records with a
> published match score, propose a value for every field we can evidence, show the document and
> page each one came from, and tell you exactly what nothing supports, what two of your documents
> disagree about, and what needs your judgement.

The claim is **provenance, not correctness**. Two words are deliberately absent — *autonomously*
and *zero* — and two more are **not claimed of the checks**: they are deterministic, and they are
not *gate-qualified*, because G4 admits 0. And **nothing bounds RECALL** — we measure the rules
that were proposed, never the ones nobody proposed.

**The guardrail trigger is MECHANICAL, never the model's confidence:** *is there a grounded
observation that re-verifies byte-exact?* Yes → propose. No → ask. LLM confidence is measurably
overconfident, and W0-C had similarity locate return SUPPORTED **20 of 20** on DELETED evidence.

## 6. Closing a phase

1. `make greps` — exit 0, **checked**
2. `CDFC_REQUIRE_RUN=1 pytest tests -q` — nothing else touching the tree, exit code **captured**
3. `python tools/nc_sweep.py` then `python tools/gate_liveness.py`
4. `make progress` and `python tools/audit_trail.py`
5. Rows in `docs/AUDIT-TRAIL.md` for every decision, measurement, correction and defect
6. Update `docs/PLAN.md` — status, and what it does NOT establish
7. Commit. **Never add a `Co-Authored-By: Claude` trailer.**

## 7. THREE numbering sequences

`P0`–`P15` are the **build** phases (`docs/measurements/P*.md`). `A0`–`A5` plus `A1c` are the
**ANCHOR architecture** phases. `B1`–`B4` are **BUILD-B** (`docs/BUILD-B.md`), and `C0`–`C5` the
current **any-corpus/any-template** sequence. `src/cdfc/gates.py:PHASE_RE` is the registry's list
and it is bounded on purpose — a phase that does not exist must not be admissible.

## 8. Report honestly

State what was measured and what was not. If a phase is one of three uses, say so. If a comparison
had a confound, name it — three harness bugs in `N4` each flattered our own implementation, and one
would have let us publish a rout. **A favourable number from an unfair harness is worse than no
number.**
